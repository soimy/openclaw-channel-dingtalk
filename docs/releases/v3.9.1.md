# v3.9.1 发布说明

本次 patch 版本修复 OpenClaw 2026.10.x 下的插件加载问题，并包含主干已合并的文档追加鉴权修复与测试稳定性修复。

## 修复

- **修复新版 OpenClaw 的 SDK 导入路径**（[PR #637](https://github.com/soimy/openclaw-channel-dingtalk/pull/637)、[Issue #636](https://github.com/soimy/openclaw-channel-dingtalk/issues/636)）：agent 路由与卡片 Stop 命令改用 `openclaw/plugin-sdk/command-auth-native`。新版宿主已移除旧的 `command-auth` 导出；此前会在加载插件时抛出 `ERR_PACKAGE_PATH_NOT_EXPORTED`。最低宿主版本仍为 `OpenClaw >=2026.8.1`，构建 SDK 仍固定为 `2026.8.1`。
- **文档追加按目标文档鉴权**（[PR #633](https://github.com/soimy/openclaw-channel-dingtalk/pull/633)）：`dingtalk.docs.append` 与兼容别名不再依据调用方自报的 `spaceId` 授权，改用 `gatewayCapabilities.docs.allowedDocIds` 校验实际写入目标。只配置 `allowedSpaceIds` 而未配置 `allowedDocIds` 时，append 会拒绝；`create` / `list` / `search` 仍按空间白名单校验。文档 RPC 能力开关继续默认关闭。
- **出站节流测试更稳定**（[PR #631](https://github.com/soimy/openclaw-channel-dingtalk/pull/631)）：跨账号隔离断言使用 fake timers，消除毫秒边界导致的偶发失败；运行时节流行为不变。

## 验证

- 用户 / 作者已报告在钉钉、Telegram、Discord 渠道完成真机冒烟测试。本次核查的运行环境为 **OpenClaw 2026.10.7 / Node v26.12.1**；这些真机结果由用户提供。
- 另在隔离的官方 **OpenClaw 2026.10.6** 发布包与完整依赖环境中验证完整插件导入、原生 SDK helper 下的模拟定向命令及 Stop 目标会话组装，并通过相关 56 项测试。
- 隔离 helper 检查不等同于真实客户端消息或真实任务取消；不将上述用户报告表述为 2026.10.6 真机测试，也不额外声明未单独报告的逐项交互结果。

## 升级提示

- 常规钉钉消息使用无需调整配置，最低宿主要求不变。
- 若已开启文档 RPC 并使用空间白名单，需要继续使用 append 时，应把允许写入的文档显式列入 `channels.dingtalk.gatewayCapabilities.docs.allowedDocIds`。详见[文档 RPC 配置](https://dingtalk-channel.nanoo.app/user/reference/gateway-rpc)。
- 本版本相对 v3.9.0 的代码范围为上述三个已合并 PR；曾尝试的 ClawHub reusable workflow 迁移已撤回，不构成本次净变更。
